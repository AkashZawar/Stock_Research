What is this tab for?

Use this when you want the argument, not just the answer. It takes the same verified report as the Stock Analysis tab and runs it through four specialist desks that argue both sides, so you can see which evidence actually drives the call and where the desks disagree. Every claim is derived arithmetically from the data - there is no language model involved, so the same input always gives the same verdict.

What it shows you

  • Analyst team - technical, fundamental, positioning, and macro desks with a stance and confidence each
  • Desk disagreements - where one desk is bullish and another bearish on the same stock
  • Bull vs bear debate - the strongest argument for each side, grouped so one trend restated four ways only counts once
  • Factor ledger - every independent driver on both sides and how much each desk contributed
  • Trader proposal - the resulting action with entry, stop, and target
  • Risk team - position size across conservative, balanced, and aggressive tiers
  • Data grounding - how much of the underlying data was actually available, which caps the desk's confidence

Debate rounds only control how much of the transcript is shown - it does not change the verdict.
